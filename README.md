# Control-CLT

Aplicação simples de controle financeiro pessoal para trabalhadores CLT.

## Funcionalidades

- Controle de entradas, despesas e saldo mensal
- Meta de reserva financeira
- Gastos agrupados por categoria
- Inclusão e exclusão de lançamentos
- Dados armazenados localmente no navegador
- Layout responsivo para computador e celular

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno. Não é necessário instalar dependências.
